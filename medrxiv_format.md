Manuscript Files
*File Upload: 	Manuscript File: You may submit your manuscript either as a single PDF file - or as separate text and figure files, from which we will automatically create a PDF.

The system handles most common word processing formats; however, Word and PDF are preferred. To ensure that the resulting PDF file is readable, we recommend that you use only certain fonts in your Microsoft Word or WordPerfect document: Times, Times New Roman, Courier, Helvetica, Arial, and the Symbol font for special characters. Using other fonts will make the PDF more difficult to read. If your file is in LaTex format, please submit it as a PDF file (you may include the .tex file as supplementary data).

Image File(s): Image and table file formats accepted are GIF, TIFF, EPS, JPEG and Powerpoint. Figures should be sized to fit on a regular printed page to avoid problems when the PDF is created. For tables, the system also accepts most common word processing formats. Formats not supported include the following: Any file utilizing OLE (Object Linking and Embedding) technology to display information or embed files, Bitmap (.bmp), PICT (.pict), Excel (.xls), Photoshop (.psd), Canvas (.cnv), CorelDRAW (.cdr) and locked or encrypted PDFs.

Your images will be converted to PDF and appended to your manuscript file. You should provide labels for any image files you upload.

Note: If your manuscript file is a complete PDF file with images included and this is the initial submission of your manuscript, you do not need to send any other files. You will be required to upload all of your primary, or source, files at revision, even if you are uploading a complete PDF.

Supplemental File(s):Select this option if you would like to include data supplements. Note: Supplemental files are not converted to PDF.

Please label your supplemental file(s).

Filenames should not include symbols or punctuation (except hyphen, underscore and file-type extensions).

NOTE: Ensure Word .txt files have text encoding that is Unicode, or UTF-8, to avoid potential conversion problems.
